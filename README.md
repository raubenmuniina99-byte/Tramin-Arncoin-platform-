# Tramin Arncoin Platform

A comprehensive trading, mining, and P2P marketplace platform with real-time market predictions and automated settlement.

## Features

- **Trading**: Predict market movements (rise/fall) with 30-second settlement cycles
- **Mining**: Rent hashrate power to mine Arncoin
- **P2P Trading**: Buy and sell Arncoin with automatic matching
- **Wallets**: G-Wallet (fiat), M-Wallet (mining earnings), and P2P integration
- **Admin Dashboard**: Complete control over market times, pricing, and user management

## Project Structure
